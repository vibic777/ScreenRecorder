# Проверка надёжности 0.9.9 — 2026-09-30

## Захват монитора

- Исправлено незаметное повторное кодирование последнего кадра WGC после остановки callback. Сессия, закрытая Windows, повреждённый кадр и отсутствие свежих кадров дольше двух секунд переключают источник на MSS.
- В callback проверяются размер массива, BGRA-формат и границы кадрирования. Исключения callback сохраняются под блокировкой и обрабатываются потоком записи вместо тихого сбоя фонового потока.
- После перехода на MSS прекращается WGC-сессия. Ошибки MSS остаются видимыми записывающему потоку и корректно завершают запись.

## Проверки

- Modern: полный набор unittest, compileall, pip check и проверки JS/расширения.
- Legacy: Python 3.8 compileall, pip check и import-smoke.
- Оба Windows EXE собираются из одного чистого коммита и проходят standalone synthetic/window self-tests. Проверка физического монитора нацелена на Windows-сеанс пользователя и не выполняется в автоматическом процессе сборки.
- Windows 8/8.1 и Linux требуют проверки на целевых системах.
