# ScreenRec — план доработок

Статус на 17.09.2026: текущий рабочий пункт — **8.1: совместимость Windows 7/8/8.1 и Linux-аудит**.

## Что уже сделано

- Запись монитора, области, окна и вкладки браузера.
- Каталог записей со встроенным проигрывателем.
- Кнопка удаления выбранной записи с подтверждением.
- Настройки формата, качества, FPS и аудио.
- Имя файла, наложения картинки/текста, темы, трей и логирование.
- Сборка Windows EXE.
- Основа локализации: `localization.py`, словари `en.json` и `ru.json`.
- Отдельное меню выбора языка; выбор сохраняется в настройках.
- Язык по умолчанию — English.
- `pytest` добавлен в dev-зависимости; тесты проигрывателя проходят.
