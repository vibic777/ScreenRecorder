# Сохранение видео при отказе аудио — 2026-10-03

## Изменение

Если аудиоисточник завершился с ошибкой после того, как видеокадры уже записаны, приложение теперь завершает FFmpeg и переносит готовое видео в выбранный каталог без звука. Промежуточная папка с аудиофайлами сохраняется, чтобы пользователь мог восстановить их вручную. Интерфейс показывает предупреждение с путями к видео и промежуточным данным.

Ошибки захвата видео и кодирования по-прежнему считаются ошибками записи. Если отказ аудио происходит до получения первого кадра, запись не создаёт пустой ролик.

## Проверки

- Добавлена регрессионная проверка успешного сохранения видео и сохранения промежуточного аудио при ошибке `AudioSession.finish()`.
- Проверки сборки Modern и Legacy выполняются релизным сценарием `scripts/release_windows.bat`: unittest для Modern, compile/import smoke для Legacy, сборка EXE обоих профилей и автономные synthetic/window/region проверки.
- Для Windows 8/8.1 запуск готового Legacy EXE на целевой ОС остаётся отдельной ручной проверкой.
