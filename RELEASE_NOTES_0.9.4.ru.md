# ScreenRec 0.9.4

В выпуск входят две сборки Windows x64:

- **Modern** — Windows 10 1809 и новее / Windows 11, PySide6 и Python 3.13.
- **Legacy** — Windows 8 / 8.1, PySide2 и Python 3.8.

Изменения в выпуске:

- **Проигрыватель Legacy на Windows 8.1:** выбор записи больше не подвешивает проигрыватель. Убраны `QVideoProbe` и «прогрев» play/pause для первого кадра, из-за которых зависал WMF; превью-кадр и снимок кадра теперь декодируются FFmpeg в фоновом потоке, на паузе показывается сам `QVideoWidget`. Повторная загрузка того же файла после сохранения записи пропускается. Ползунок громкости Legacy теперь управляет проигрывателем (раньше он не действовал).
- **Локализация:** около 60 сообщений об ошибках записи, звука, окон, вкладки, наложений, имён файлов, логгера и запуска были жёстко заданы по-русски и в английском интерфейсе выводились по-русски; теперь они следуют языку интерфейса. Переведены сводка качества/звука в главном окне и форматы даты/времени в конструкторе имени. Добавлены отсутствовавшие ключи `language.changed_title` и `language.restart_required` — диалог смены языка больше не показывает имена ключей. Исправлены буквальные `\n` в диалогах импорта профиля, удаления записи и сохранения расширения; удалены дубликаты ключей в локалях.
- **Папка записей:** смена папки записей больше не приводит к падению `NameError`.
- **Подсказки** подключены для поиска, сортировки, списка, шкалы, громкости и скорости проигрывателя и для галочки нескольких копий.
- **Документация** описывает обе сборки Modern/Legacy, их окружения и отличия, семь тем (по умолчанию серая) и ограничения Legacy-захвата окна; `scripts/setup_venv_windows.bat` создаёт `.venv` явно на Python 3.13.

SHA-256 для обоих EXE приложены в `SHA256SUMS.txt`. Пользователь проверил 0.9.3 (Modern на Windows 10/11, Legacy на Windows 8.1); 0.9.4 проверен только на хосте сборки. Перед рабочим использованием проверьте нужные источники захвата и режимы звука в своей среде.

Проверки: на хосте Windows 11 прошли 54 теста и 9 под-тестов; Legacy-исходники компилируются и импортируются на Python 3.8/PySide2; обе автономные сборки прошли self-test синтетической записи, наложения, логгера и проигрывателя.
