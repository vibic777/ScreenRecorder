# Исправление падения при записи области — 2026-09-30

## Разбор логов Windows 10 и Windows 11

В обоих новых логах запуск обрывался на `Capture worker: entering screen source`. Windows 10 запускал область 72×121 при 60 FPS с микрофоном; Windows 11 — область 1072×577 при 30 FPS без звука. Следовательно, сбой был общим для старта источника области и не зависел от версии Windows, аудио или размера региона. Python traceback и системный crash dump отсутствовали, что указывало на аварийный выход из нативного WGC пути.

## Исправление

- Modern теперь открывает MSS для выбранного региона и получает первый кадр при открытии источника. Этот кадр переиспользуется worker-ом, повторного пробного захвата нет.
- MSS захватывает только выбранную область; WGC больше не запускается для регионов. Полный монитор продолжает использовать WGC.
- Если MSS не может открыть регион, ошибка передаётся в worker и интерфейс показывает сообщение; нативный WGC вызов не запускается и процесс остаётся работоспособным.

## Проверки

- MSS реально захватил обе области из логов: 72×121 и 1072×577.
- Полный GUI-путь с WGC для региона и записью аудио отдельно проверялся; регрессионные тесты теперь фиксируют MSS-путь и отказ MSS без WGC.
- Modern: полный unittest, compileall, pip check. Legacy: compile/import smoke и pip check.
- Релизный конвейер проверяет каждый EXE на synthetic, реальном окне и реальной выбранной области; целевые компьютеры пользователя Windows 10/11 недоступны для автоматической проверки.
