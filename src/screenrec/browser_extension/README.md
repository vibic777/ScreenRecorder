# Локальное расширение ScreenRec

Chrome/Edge 116 или новее. Расширение нигде не публикуется.
1. Откройте chrome://extensions или edge://extensions.
2. Включите режим разработчика → «Загрузить распакованное» → выберите эту папку.
3. В ScreenRec выберите «Вкладка браузера» и «Начать запись». Скопируйте код подключения.
4. Откройте нужную вкладку, нажмите значок расширения, вставьте код и нажмите «Подключить и записывать эту вкладку».
5. Останавливайте запись из ScreenRec или расширения. Подождите завершения обработки видео.

Можно переключать вкладки: захват остаётся привязан к исходной. Закрытие исходной вкладки заканчивает захват.
Защищённое видео и служебные страницы браузера могут быть недоступны.
Настройки звука в ScreenRec: микрофон и/или системный звук компьютера; системный звук включает другие программы.
Связь только с 127.0.0.1, отдельный случайный код на каждый сеанс. Код действует, пока открыт сеанс в ScreenRec.
