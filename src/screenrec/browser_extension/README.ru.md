# Расширение ScreenRec для браузера

Локальное расширение Chrome/Edge для записи текущей вкладки через ScreenRec. Требуется Chrome/Edge версии 116 или новее. Расширение нигде не публикуется.

1. Откройте chrome://extensions или edge://extensions.
2. Включите режим разработчика, выберите **Загрузить распакованное** и укажите эту папку.
3. В ScreenRec выберите **Вкладка браузера** и нажмите **Начать запись**. Скопируйте код подключения.
4. Откройте нужную вкладку, нажмите значок расширения, введите код и выберите **Подключить и записывать эту вкладку**.
5. Остановите запись из ScreenRec или расширения. Дождитесь завершения обработки видео.

Вкладки можно переключать: захват остаётся привязан к исходной вкладке. Закрытие исходной вкладки завершает захват. Защищённое видео и служебные страницы браузера могут быть недоступны.

Настройки звука задаются в ScreenRec. Расширение связывается только с 127.0.0.1 и использует случайный код для каждого сеанса. Код действует только пока открыт сеанс вкладки в ScreenRec.
