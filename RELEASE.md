# Релиз ScreenRec 0.2.0

## Запуск

Запустите ScreenRec.exe. Python и отдельный FFmpeg не нужны. Выберите монитор, папку и параметры в конфигураторе, затем начните запись. По умолчанию звук выключен. Крестик сворачивает приложение в трей, «Файл → Выход» завершает его.

Сборка Windows x64 проверена на Windows 11. Linux-бинарник не входит в релиз.

## Комплект

Каталог releases/0.2.0/ содержит ScreenRec.exe, ZIP приложения и исходников, README.md, AGENT.md, CHANGELOG.md, RELEASE.md, requirements-windows-lock.txt, manifest.json и SHA256SUMS.txt.
Манифест указывает точный Git-коммит. Проверить SHA-256 можно через Get-FileHash -Algorithm SHA256 <файл>.

## Следующий релиз

1. Обновить код, AGENT.md, README.md, CHANGELOG.md и инструкции.
2. Обновить версию в pyproject.toml и документации; не перезаписывать выпущенную версию.
3. Настроить venv через scripts/setup_venv_windows.bat. Все установки, тесты и сборки — внутри venv.
4. Выполнить python -m unittest discover -s tests -v и python -m pip check.
5. Проверить изменения, создать коммит; git status --porcelain должен быть пустым.
6. Запустить scripts/release_windows.bat: он проверяет Git и зависимости, запускает тесты, собирает один EXE, проверяет его без Python в PATH на искусственном кадре без звука, создаёт архивы и контрольные суммы.
7. При изменении звука проверить нужные режимы scripts/smoke_exe.ps1; при изменении захвата — реальную запись.
8. После успешной проверки создать аннотированный тег git tag -a v0.2.0 -m "ScreenRec 0.2.0" (для следующего релиза подставить его версию).

Готовый каталог релиза не перезаписывается. После ошибки остаётся каталог .pending; повторный запуск продолжает подготовку в нём.
Артефакты, venv и тестовые записи не коммитятся. Удалённый репозиторий пока не настроен: коммит, тег и релиз локальные. Для публикации нужны адрес репозитория и место размещения.
