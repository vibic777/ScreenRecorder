# ScreenRec 0.9.3

В выпуск входят две сборки Windows x64:

- **Modern** — Windows 10 1809 и новее / Windows 11, PySide6 и Python 3.13.
- **Legacy** — Windows 8 / 8.1, PySide2 и Python 3.8.

Добавлен legacy-порт, исправлены совместимость Qt5-проигрывателя и комплектация мультимедийных плагинов Windows, подготовка наложений и предпросмотр текста. Расширена диагностика захвата, кодировщика и проигрывателя.

SHA-256 для обоих EXE приложены в `SHA256SUMS.txt`. Пользователь проверил Modern на Windows 10/11, а Legacy — на Windows 8.1. Перед рабочим использованием проверьте нужные источники захвата и режимы звука в своей среде.

Проверки: на хосте Windows 11 прошли 48 тестов и 9 под-тестов; обе автономные сборки прошли self-test синтетической записи, наложения, логгера и проигрывателя. Дополнительно пользователь проверил Modern на Windows 10/11 и Legacy на Windows 8.1.
