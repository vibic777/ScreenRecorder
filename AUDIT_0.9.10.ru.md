# Исправление запуска захвата на Windows 10 — 2026-09-30

## Причина

В `dist/modern/screenrec.log` запуск обрывался непосредственно после входа в источник экрана, без Python traceback и без события Windows Error Reporting. Лог включал передачу `cursor_capture=True` в нативную библиотеку Windows Graphics Capture.

Windows Graphics Capture доступен начиная с Windows 10 1803, но свойство с настройкой захвата курсора добавлено только в Windows 10 2004 (сборка 19041). Передача этого параметра на более старых системах могла оборвать запуск в нативном слое до появления кадра. Теперь приложение задаёт его только на поддерживающих сборках. На Windows 10 1809–1909 остаётся системное значение по умолчанию.

## Проверки

- Добавлен тест порога Windows 10 build 19041 и поведения при недоступной информации об ОС.
- Проверены реальные WGC захват 1072×577 и полное начало/остановка записи через GUI с текстовым наложением; оба сценария успешны на тестовой Windows-системе.
- Минимальная ОС Modern ограничена Windows 10 1809, соответствующей поддерживаемой платформе Qt 6.11.
- Система пользователя Windows 10, но её точная сборка в приложенческом логе отсутствовала. Старую сборку Windows 10 в этой среде проверить невозможно.
